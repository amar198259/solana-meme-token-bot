# 🤖 بوت تداول عملات الميم على سولانا

بوت Telegram ذكي لتداول عملات الميم على شبكة سولانا **مجاني تماماً بدون رسوم إضافية** ✨

## ✨ الميزات الرئيسية

- 🛒 **شراء عملات الميم** - اشتري أي عملة ميم بسهولة
- 💵 **بيع العملات** - بع محفظتك بنقرة زر
- 💰 **عرض الرصيد** - راقب رصيدك من SOL في الوقت الفعلي
- 📊 **المحفظة الذكية** - تتبع كل عملاتك والأرباح والخسائر
- 📈 **تحليل الأسعار** - احصل على معلومات مفصلة عن أسعار العملات
- 🔐 **أمان عالي** - محفظة محمية بمفتاح خاص آمن
- ✅ **بدون رسوم خفية** - جميع المعاملات مباشرة على السلسلة

## 🚀 البدء السريع

### المتطلبات

- Node.js 18+
- npm أو yarn
- محفظة سولانا

### التثبيت

1. **استنسخ المستودع:**
```bash
git clone https://github.com/amar198259/solana-meme-token-bot.git
cd solana-meme-token-bot
```

2. **ثبت المكتبات:**
```bash
npm install
```

3. **أعد ملف متغيرات البيئة:**
```bash
cp .env.example .env
```

4. **املأ بيانات البيئة:**
```env
# احصل على توكن البوت من @BotFather على Telegram
TELEGRAM_BOT_TOKEN=your_bot_token_here

# أضف مفتاح محفظتك (Base58 encoded)
WALLET_PRIVATE_KEY=your_private_key_here

# استخدم devnet للاختبار أولاً
NETWORK=devnet
```

### تشغيل البوت

```bash
npm start
```

أو في وضع التطوير:
```bash
npm run dev
```

## 📱 استخدام البوت

### الأوامر الأساسية

| الأمر | الوصف |
|-------|-------|
| `/start` | ابدأ واستقبل المساعدة |
| `/balance` | عرض رصيدك من SOL |
| `/buy` | شراء عملة ميم |
| `/sell` | بيع عملة من محفظتك |
| `/price` | البحث عن سعر عملة |
| `/portfolio` | عرض محفظتك كاملة |
| `/menu` | القائمة الرئيسية |

### خطوات الشراء

1. انقر على 🛒 شراء أو أكتب `/buy`
2. الصق عنوان العملة (Token Address)
3. أدخل المبلغ بـ SOL (مثال: 0.5)
4. أنتظر تأكيد المعاملة ✅

### خطوات البيع

1. انقر على 💵 بيع أو أكتب `/sell`
2. الصق عنوان العملة
3. أدخل الكمية المراد بيعها
4. أنتظر استقبال SOL في محفظتك ✅

## 🐛 استكشاف الأخطاء

### المشكلة: "Invalid wallet address"
**الحل:** تأكد من وضع مفتاحك الخاص بصيغة Base58 الصحيحة

### المشكلة: "Insufficient balance"
**الحل:** تأكد من وجود رصيد كافي من SOL في محفظتك

### المشكلة: "Token not found"
**الحل:** تأكد من صحة عنوان التوكن وأنه موجود على سولانا
